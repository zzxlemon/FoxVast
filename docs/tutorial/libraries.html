FoxLang 函数库参考

FoxVast VM 1.3.210+b1 · 系统函数库
语言参考 函数库参考

1. 导入函数库

系统库以 DLL 形式提供(fox.<lib>.dll,位于可执行文件旁或 dlls/)。使用前必须先 import,并且所有调用都使用点号写法:

import fox.std.util -> u
import fox.gl.fg -> fg

println(u.length("hello"))     # 5
fg.create_window("Demo", 800, 600)

所有函数库在参数非法或参数个数不对时会抛错,可用 try/catch 捕获。

2. math — import fox.std.math

三角函数,参数为弧度;参数须为 int 或 double,返回 double。

函数结果
math.sin(x)正弦。
math.cos(x)余弦。
math.tan(x)正切(π/2 附近会发散)。

示例

import fox.std.math -> m
println(m.sin(1.5707963))   # 约 1.0

3. random — import fox.std.random

函数结果
random.random("int", min, max)[min, max] 闭区间内的随机整数。
random.random("double", min, max)[min, max) 区间内的随机浮点数。

min > max 会抛错。首次使用时以系统时钟为种子。

示例

import fox.std.random -> r
d = r.random("int", 1, 6)     # 掷骰子,1..6

4. util — import fox.std.util

通用

函数结果
util.length(x)数组元素个数 / 字符串字节数 / 字典键数。

类型转换

函数结果
util.IntChangeString(i)字符串。
util.StringChangeInt(s)整数(输入非法时抛错)。
util.StringChangeDouble(s)浮点数(输入非法时抛错)。
util.DoubleChangeString(d)字符串(固定 6 位小数,如 "1.000000")。
util.DoubleChangeInt(d)整数,向零截断。
util.IntChangeDouble(i)浮点数。

数组操作(都返回新数组,不修改原数组)

函数结果
util.arr_append(arr, v)尾部追加 v 后的数组。
util.arr_pop(arr)去掉最后一个元素的数组(空数组抛错)。
util.arr_contains(arr, v)包含返回 1,否则 0(深比较)。
util.arr_slice(arr, start, end)子数组;下标自动夹取,end 不包含。
util.arr_sort(arr)升序排序的数组(元素须全为数字或全为字符串)。
util.arr_length(arr)元素个数。

字符串操作(按字节处理,不支持 UTF-8 语义)

函数结果
util.str_contains(s, sub)包含 sub 返回 1,否则 0。
util.str_replace(s, old, new)替换所有出现;old 为空时原样返回 s。
util.str_split(s, sep)字符串数组;分隔符为空时按单个字符拆分。
util.str_trim(s)去掉首尾空格、制表符、CR、LF。
util.str_lower(s)转小写(仅 ASCII)。
util.str_upper(s)转大写(仅 ASCII)。
util.str_substring(s, start, end)按字节取子串,end 不包含,下标自动夹取。
util.str_length(s)字节数。

示例

import fox.std.util -> u
arr = [3, 1, 2]
arr = u.arr_sort(arr)                    # [1, 2, 3]
println(u.arr_length(arr))               # 3
println(u.str_replace("a-b-c", "-", "+"))# a+b+c

5. file — import fox.sys.io.fs

文件句柄是不透明的整数,从 1 开始。同一文件不能重复打开。所有访问均为二进制模式。

函数结果
file.file_open(name, mode)整数句柄。模式:"read"(读)、"write"(写,截断)、"append"(追加)。
file.file_read(handle)整个文件的字符串内容(仅读模式)。
file.file_write(handle, txt [, 换行])写入文本;第三个参数为 1 时追加换行。
file.file_close(handle)关闭文件。
file.file_remove(name)删除文件(必须先关闭)。

示例

import fox.sys.io.fs -> file
h = file.file_open("data.txt", "write")
file.file_write(h, "hello", 1)
file.file_close(h)

6. socket — import fox.std.socket

仅 TCP 客户端、阻塞式、IPv4。句柄是不透明的整数,从 1 开始。

函数结果
socket.socket_create()整数句柄。
socket.socket_connect(h, ip, port)成功返回 1;连接建立前会阻塞。
socket.socket_send(h, data)整数:实际发送的字节数。
socket.socket_recv(h, size)收到的字节串(可能短于 size;对端关闭时返回空串)。有数据前会阻塞。
socket.socket_close(h)关闭连接。

示例

import fox.std.socket -> s
h = s.socket_create()
s.socket_connect(h, "127.0.0.1", 8080)
s.socket_send(h, "GET / HTTP/1.0\r\n\r\n")
reply = s.socket_recv(h, 4096)
s.socket_close(h)

7. time — import fox.sys.time

单位都是整秒(32 位整数,2038 年前后溢出)。使用本地时间。

函数结果
time.now()整数:自 1970-01-01 00:00 UTC 起的秒数。
time.format([格式])strftime 格式化的当前本地时间,默认 "%Y-%m-%d %H:%M:%S"。
time.field("名称")整数分量:year(年)、month(1–12)、day、hour、minute、second、weekday(0–6,周日为 0)、dayofyear/yearday(0–365)。

示例

import fox.sys.time -> t
println(t.format())            # 2026-08-19 12:00:00
println(t.field("year"))       # 2026

8. gl_fg — import fox.gl.fg(OpenGL 图形)

单窗口 OpenGL 3.3 / GLFW 渲染库。坐标以像素为单位,原点在左上角,y 轴向下。颜色为 0–1 的浮点数。

窗口生命周期与计时

函数结果
gl_fg.create_window(title, w, h)窗口索引(0)。同一时间只允许一个窗口。
gl_fg.close()释放窗口、纹理和 GLFW。
gl_fg.window_should_close(win)窗口关闭标志置位时返回 1。
gl_fg.swap_buffers(win)交换前后缓冲。
gl_fg.poll_events()处理窗口与输入事件。
gl_fg.update(win)swap_buffers + poll_events,并更新 frame_time。
gl_fg.time()double:GLFW 初始化以来的秒数。
gl_fg.frame_time(win)double:上一帧耗时(秒),由 update 更新。
gl_fg.window_size(win)数组 [w, h](像素),随窗口缩放实时变化。

绘图

函数结果
gl_fg.clear_color(r, g, b, a)设置清屏颜色(0–1 浮点)。
gl_fg.clear()清空颜色缓冲。
gl_fg.draw_triangle(x1,y1,r1,g1,b1, x2,y2,r2,g2,b2, x3,y3,r3,g3,b3)实心三角形;每个顶点可以有不同的颜色。
gl_fg.draw_rect([x,y,r,g,b], [..], [..], [..])由 4 个五元素数组(左上、右上、右下、左下)绘制的实心四边形;每顶点独立颜色。
gl_fg.draw_line(x1, y1, x2, y2, 粗细, r, g, b)单色直线。
gl_fg.draw_circle(cx, cy, radius, r, g, b)实心圆(64 段扇面)。
gl_fg.draw_text(字体文件, 文本, x, y, 字号, r, g, b)用 TTF 字体绘制文本;仅 ASCII 32–127。字体按给定路径、$FGFONT_DIR、exe 旁的 fonts/、当前目录依次查找。
gl_fg.load_texture(win, 文件)由 PNG/JPG/BMP/GIF 加载纹理,返回整数 id;按路径缓存(最多 256 个)。
gl_fg.draw_image(win, tex, x, y, w, h)绘制纹理,左上角在 (x, y)。
gl_fg.draw_image_rotated(win, tex, x, y, w, h, 角度)绕中心旋转绘制;角度单位度,顺时针(y 向下坐标系)。
gl_fg.draw_image_tinted(win, tex, x, y, w, h, r, g, b, a)着色绘制;(1,1,1,1) 为原样,alpha 可做淡出。
gl_fg.image_size(win, tex)数组 [w, h](像素)。

逻辑分辨率缩放(可选)

函数结果
gl_fg.set_scale(win, 逻辑宽, 逻辑高)按逻辑分辨率缩放绘制,保持宽高比完整适配,锚点在左上。(0, 0) 关闭缩放。
gl_fg.set_scale_anchor(win, 逻辑宽, 逻辑高, ax, ay)同上,可自定义锚点,取值 [0, 1]:0 = 左/上,0.5 = 居中,1 = 右/下。

开启缩放后,鼠标坐标会映射回逻辑坐标。关闭缩放时,一个逻辑单位等于一个像素。

输入

函数结果
gl_fg.mouse_down(win, 按键)按住时返回 1。按键:0 = 左键,1 = 右键,2 = 中键。
gl_fg.mouse_pos(win)数组 [x, y];(0,0) 在左上角。
gl_fg.mouse_wheel(win)double:距上次查询累计的垂直滚轮量;读取后清零。
gl_fg.key_down(win, 键名)按住期间返回 1。
gl_fg.key_pressed(win, 键名)每次物理按下触发一次 1;查询后被消费。
gl_fg.key_released(win, 键名)每次松开触发一次 1;查询后被消费。
gl_fg.key_any_pressed(win)自上次查询起有任意键按下返回 1,并清空所有待处理按键。

键名:单个可打印字符("p"、"="、"-" ...)、数字,或 space enter escape tab backspace up down left right home end pageup pagedown insert delete shift ctrl alt f1..f12。

UI 控件

函数结果
gl_fg.button(win, x, y, w, h, 字体, 文本)绘制灰色按钮(悬停/按下变暗),文本白色居中;悬停时每次点击返回 1。
gl_fg.text_input(win, x, y, w, h, 字体, 字号)绘制文本框并返回其内容。点击聚焦,输入编辑,Backspace 删除,Enter 提交整行并清空。
gl_fg.simulate_click(win [, 次数])排队模拟左键点击(默认 1 次),由下一次 mouse_down(win, 0) 或悬停的按钮消费。

示例 — 最小游戏循环

import fox.gl.fg -> fg

fg.create_window("Demo", 800, 600)
while (fg.window_should_close(0) == 0) {
    fg.clear_color(0.10, 0.10, 0.16, 1.0)
    fg.clear()
    if (fg.key_down(0, "escape") == 1) { exit(0) }
    fg.draw_rect([100, 100, 1.0, 0.4, 0.4],
                 [200, 100, 1.0, 0.4, 0.4],
                 [200, 200, 1.0, 0.4, 0.4],
                 [100, 200, 1.0, 0.4, 0.4])
    fg.update(0)
}
fg.close()

9. 协程(虚拟机内置)

co.* 不需要 import,直接由字节码虚拟机提供。参见语言参考的协程一节。

10. 插件

外部 .fox/.foxlib 脚本可用 !import 名称 引入(依次在脚本目录、C:\FoxLibs、当前目录查找)。系统库也会从 C:\FoxLibs、C:\Program Files\FoxVast\Libs、./libs 和当前目录解析。
