FoxLang 语言参考

FoxVast VM 1.3.210+b1 · 64 位字节码虚拟机
语言参考 函数库参考

1. 运行程序

FoxLang 先把 .fox 源代码编译为 .fc 字节码,再执行字节码。每个程序必须定义顶层函数 main,它是程序入口。

命令说明
fox -c prog.fox编译为 prog.fc(生成在源码旁边)。
fox -fc prog.fc运行字节码(第一个文件是入口,其余文件作为模块加载)。
fox -d prog.fc反汇编字节码。
fox -p out.far a.fox b.fox打包程序为 .far 归档(第一个文件是入口)。
fox -u arch.far [目录]解包 .far 归档(默认输出到 output/)。
fox -far arch.far运行归档中的入口程序。
fox -s utf-8|gbk设置控制台编码。
fox -version显示版本信息。

.far 是普通 ZIP(仅存储、不压缩),其中包含编译好的 .fc 文件(位于 src/ 下)。

func main() -> void {
    println("Hello, FoxLang")
    exit(0)
}

2. 词法结构

注释

  • # — 行注释,到行尾结束。
  • #* ... *# — 块注释(不可嵌套)。

字面量

字面量示例说明
整数 int42仅十进制数字;32 位范围。不支持十六进制/下划线/指数。负数用 -。
浮点 double3.14数字最多带一个 .。
字符串"hi"只能用双引号(不能用单引号)。允许跨多行。
数组[1, 2, 3]允许末尾逗号。
字典{"k": 1, "n": 2}键必须是字符串字面量或裸标识符。允许末尾逗号。
字节串 bytesnew(1024)零填充的字节缓冲区;没有字节串字面量。

字符串转义

\" \\ \/ \b \f \n \r \t \e(ESC,可用于 ANSI 颜色),\uXXXX(Unicode 码点,编码为 UTF-8)。未知转义原样保留。

关键字

func void int double string print println ret if else while for break continue and or !(逻辑非) new class struct dict try catch error exit import !import yield input goto free free_all endl

以 ; 结尾的语句是错误:FoxLang 用换行作为语句结束符。; 只出现在 for 头部。

签名类型 vs 运行时类型

签名中可声明的类型运行时值类型
int、double、string、dict、void;字段还可用 new(即 bytes)Int、Double、String、Void、Array、Bytes、Dict、Object、Coroutine

变量本身是动态类型的:运行时在 ret 处检查声明的返回类型,运算按实际值类型在编译期/运行期检查。

3. 变量与赋值

语言没有变量声明。name = expr 会创建或覆盖一个变量。所有变量位于同一个扁平命名空间中,整个程序共享(函数体不引入作用域),因此参数名与顶层名字不能冲突。

形式含义
a = expr创建或覆盖变量 a。赋值是语句,不是表达式。
a[i] = expr对数组/字典/字节串值按下标写入。
obj.field = expr对象字段写入。
obj.field[i] = expr对象字段按下标写入。
int x = 5带类型声明(int/double/string/dict),创建一个全局变量,仅字节码模式支持。int x 单独写是无操作。
free(name)删除一个变量。
free_all()删除所有变量。

4. 运算符与优先级

优先级运算符结合性
最高-x 取负、!x 逻辑非(结果为 int 1/0)—
* / %左
+ -左
== != > < >= <=左
最低and、or(短路求值)左
  • 没有 +=/++/复合赋值,没有三元运算符。
  • int 与 double 混用做算术或比较是编译错误,需用 double(x)/int(x) 显式转换。
  • string + string 拼接;string + int 是编译错误,数字用 util.IntChangeString 或 util.DoubleChangeString 转换。
  • 比较产生 int 1/0。字符串只支持 ==/!=,用 </> 等会比较会报错。
  • ==/!= 对数组、字典、字节串、对象做深比较。

下标 arr[i](数组、字典、字节串)与成员访问 obj.field 的绑定比算术运算符更紧。

5. 语句

条件判断

if (score > 100) {
    println("high")
} else {
    println("low")
}

单个语句可以省略花括号。else if 通过嵌套实现。条件接受 int(0 为假)、double,以及非空数组/字典/字节串;字符串不能作为条件。

循环

while (i < 10) {
    i = i + 1
}

for (k = 0; k < 5; k = k + 1) {
    if (k == 2) continue
    println(k)
}

支持 break 和 continue;for 条件留空表示无限循环。

函数

func add(a <- int, b <- int) -> int {
    ret a + b
}

func log(msg <- string) -> void {
    println(msg)
}
  • 参数类型: int、double、string、dict。
  • 返回类型写在 -> 后;允许 void、int、double、string、dict。省略 -> 类型 即 void。类型后可加冒号:func f() -> int : { ... }。
  • ret expr 返回值;裸 ret 只在 void 函数中合法。非 void 函数的每条路径都必须产生返回类型的值。
  • 调用期间参数会作为全局变量绑定,返回后自动恢复。

输入输出

语句含义
print(x)输出,不换行。
println(x)输出并换行。
endl只输出一个换行。
input() -> var从标准输入读取一行(字符串)存入 var。
exit(code)以整数退出码结束进程。

错误与异常

try {
    error("something went wrong")
} catch (e) {
    println(e)    # 输出 something went wrong
}

error(msg) 要求字符串参数,抛出可捕获的错误。函数库在参数非法时也会抛错,同样可以捕获。没有 finally。未被 try/catch 捕获的运行时错误会终止程序,并打印带源码行号的调用栈。

跳转

fn skip:
goto skip

goto label 在当前函数内跳转;标签(fn name:)按函数作用域。

6. 类与对象

class Point {
    x <- int
    y <- int
    tag <- string

    init(x0 <- int, y0 <- int, t <- string) -> void {
        x = x0
        y = y0
        tag = t
    }

    func describe() -> string {
        ret tag
    }
}

p = new Point(3, 4, "origin")
println(p.x)          # 3,字段读取
p.tag = "moved"       # 字段写入
println(p.describe()) # 方法调用
  • 字段类型: int、double、string、dict,以及 new(即 bytes 缓冲区)。
  • init 是构造函数。new ClassName(args) 把参数映射到 init 的参数(不含隐式 this);没有 init 时,参数按声明顺序映射到字段。
  • 方法带隐式 this;调用形式为 obj.method()。
  • struct 与 class 等价。
  • 成员访问使用点分标识符(obj.field、obj.method(...)),按最后一个点解析。

7. 类型转换

转换结果
int(x)由 int/double(截断)或 string 得到 int。
double(x)由 int/double 或 string 得到 double。

也可用函数库:util.IntChangeString、util.StringChangeInt、util.StringChangeDouble、util.DoubleChangeString、util.DoubleChangeInt、util.IntChangeDouble。int 与 double 之间没有自动转换。

8. 协程

协程是字节码虚拟机的特性;yield 在旧解释器中不支持。协程与调用方共享全局变量(参数全局量按每次 resume 段绑定)。

func task(id <- int) -> void {
    n = 0
    while (n < 3) {
        yield(n + 100 * id)
        n = n + 1
    }
}

func main() -> void {
    c = co.create("task", 1)      # 协程句柄
    v = co.resume(c)              # 运行到第一次 yield;v = 100
    v = co.resume(c)              # v = 101
    if (co.status(c) != "suspended") { ... }
    # 函数执行完后:
    if (co.status(c) != "dead") { ... }
    println(co.result(c))         # 最终返回值
    exit(0)
}
函数说明
co.create("fn", 参数...)由函数创建协程;参数绑定到它的形参。
co.resume(coro [, 值])运行到下一个 yield;返回 yield 产生的值,函数结束时返回最终返回值。值 会成为 yield 表达式的结果。
co.status(coro)"suspended"(挂起)、"running"(运行中)或 "dead"(已结束)。
co.result(coro)已结束协程的最终返回值。
yield(expr) / yield挂起当前协程。在协程之外或 co.resume 内部调用均为非法。

9. 导入

import fox.std.util -> u        # 系统库,带别名
import fox.gl.fg                # 系统库,以 gl_fg.func(...) 调用
import "other.fox"              # 跨文件源码导入(相对当前文件)

系统库以 DLL 形式提供(fox.<lib>.dll,位于可执行文件旁或 dlls/),使用前必须先 import。完整清单见函数库参考。

10. 限制与注意事项

  • 整数为 32 位(秒级时间戳在 2038 年前后会溢出)。
  • 字符串是字节序列:str_length/下标按字节计算;大小写转换仅支持 ASCII;核心不解析字符串中的 UTF-8。
  • 每次函数调用通过 new() 最多分配 512 字节(运行时上限)。
  • 没有布尔、null、switch 结构;假值包括 0、空集合、空字节串。
  • 没有运算符重载;所有运算按内置值类型分派。
  • 垃圾回收在指令/语句安全点执行;协程、对象、字典都受 GC 管理。
